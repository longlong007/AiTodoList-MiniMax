## 系统概述

**项目名称**：智能待办事项管理系统 (Smart Todo List)

**项目目标**：提供一个功能完善的待办事项管理平台，结合AI智能推荐功能，帮助用户更高效地管理和完成任务。

**核心功能**：
- 用户账号注册与登录（手机号认证）
- 待办事项的增删改查
- 任务重要性与紧急程度分类
- AI智能任务排序推荐
- 响应式Web界面

---

## 技术特点

- **前后端分离架构**：Vue.js + NestJS
- **数据库**：PostgreSQL + TypeORM
- **认证授权**：JWT (JSON Web Token)
- **AI集成**：支持智能任务排序和建议
- **容器化部署**：Docker + Docker Compose

## 快速开始

### 环境要求

- Node.js 18+
- PostgreSQL 14+
- Docker & Docker Compose

### 启动服务

```bash
# 使用Docker启动所有服务
docker-compose up -d

# 或分别启动
# 启动数据库
docker-compose up -d postgres

# 启动后端
cd backend && npm install && npm run start:dev

# 启动前端
cd frontend && npm install && npm run dev
```
